## 难点回答

1. 退款流程：分2阶段，退款请求（同步）+退款结果（异步）
   1. 退款请求在路由层做好解密解签、原文入库，键值取模计算分库
   2. 解析报文，信息入库
   3. 去下游取键值和分库，重试三次；同步发送，重试三次
   4. 回成功或失败回执，区分技术失败和业务失败
   5. 退款结果来，通过原键值，在路由层计算分库分发
   6. 报文解析校验，时序控制由本系统负责。仅已回成功回执才继续
   7. 报文入库，响应成功，异步地通知下游，失败由定时任务负责重试
   8. 异常：超时未回复，数研所推定失败；同步发下游但响应超时，我们直接回失败，下游未收到退款结果，记账模块会推定失败
   
2. 聚合查询：
   1. 界面需要1000笔报文，按日期时间ID排序，不妨假设从小到大排
   2. 极端情况可能都在同一分库，应该去每个分库查1000笔报文，查询时排好序
   3. 在聚合查询系统做好排序，取前1000笔，直接排序浪费了每个数据集的有序性，并且还要识别每个分库贡献的数量
   4. 恰好是力扣的排序k个有序数组（框架传列表只有数组），k个数组在一个大数组中
   
      1. 建堆：把K个头节点放入最小堆，堆顶就是当前最小节点
         循环：弹出堆顶节点 → 接到结果链表尾部 → 将该节点的next节点入堆
         结束：堆为空时，所有元素已按序排好
         
      2. 变动：假如结果集要更新对应分库续传键值
         优点：取最小只需Ologk，只需k的空间；



```java
public void heapSort(int[] arr) {
    int n = arr.length;
    
    // 1. 构建大顶堆（从最后一个非叶子节点开始下沉）
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }
    
    // 2. 逐个将堆顶元素移到末尾
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);          // 堆顶最大值放末尾
        siftDown(arr, 0, i);      // 重新调整堆
    }
}

private void siftDown(int[] arr, int i, int n) {
    int parent = i;
    int child = 2 * parent + 1;   // 左孩子
    
    while (child < n) {
        // 选择较大的孩子（右孩子存在且更大）
        if (child + 1 < n && arr[child + 1] > arr[child]) {
            child++;
        }
        // 父节点已经最大，结束
        if (arr[parent] >= arr[child]) break;
        // 交换父子
        swap(arr, parent, child);
        parent = child;
        child = 2 * parent + 1;
    }
}

private void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
```
